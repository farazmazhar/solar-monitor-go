# Session 2026-10-18 (second sitting)

## Done

- Go module `github.com/farazmazhar/solar-monitor-go` with Bubble Tea v2,
  Lip Gloss v2, Bubbles v2 and `charmbracelet/x/ansi`.
- Config package: defaults, TOML, env overrides, legacy `solis2kde` import,
  `--init`, validation.
- Provider package: domain model and `Source` interface.
- Demo provider: deterministic day simulation, pinned-clock option, month,
  year, alarms and a raw payload for the diagnostics browser.
- SolisCloud client: HMAC-SHA1 signing, inverter discovery, detail, day,
  month, year and alarm endpoints, unit and sign normalisation with aliases.
- SQLite store (`modernc.org/sqlite`): snapshots, samples, daily/monthly
  aggregates, alarms, pruning and stats.
- Monitor service: records snapshots, merges local samples into today's curve,
  falls back to cache when the cloud is down, seeds the first frame.
- UI: seven screens, custom braille line chart, block bar chart, sparkline,
  boxed energy-flow diagram, battery gauge, tables, help overlay, motion,
  mouse hits, JSON/CSV export, responsive layouts.
- Tests: signing golden vector, normalisation, config, demo, store, monitor,
  and golden frames at 60×20, 80×24 and 100×30.
- README, LICENSE, `--dump` debugging flag.

## Decisions

- ADR-0009: local history behind `monitor.Service`, UI stays store-agnostic.
- ADR-0010: injectable clocks for demo and golden tests.
- `fmtAgeFrom`/`fmtCountdown` take an explicit now so goldens never drift.
